# 中文页面的表达方式

2026-10-23 根据用户反馈调整：中文按中文读者的阅读习惯编写，不逐句对译。首页和功能区介绍流量记录、时间回看、程序用量及连接去向，不反复强调直连和代理均可统计。

- 功能介绍先回答用户想查什么；采集方式、管理员授权和统计边界放在开始使用、兼容说明及 FAQ 中讲清楚。
- 使用直接、具体的动词，少用「已观测进程」「采样间关闭」「可靠进程证据」「统计口径」等工程表达。
- 「采样间关闭的短连接」在详细说明中改为「很快结束的连接」；「已观测进程」改为「其他程序」或「已记录的程序」。归属确认、单来源计数等事实仍保留。
- 不靠空泛口号或刻意亲昵制造亲切感。能直接说明用途，就直接说明。
- 长 FAQ 分成两到三段，问题与答案都使用自然中文；英文回答保持原有格式。
- 原生方式每次启动需要授权、仅助手提权、回环通信、Mihomo 漏记、不能精确分摊会话 GB、token 非额度等边界不能因润色而删除。

这轮更新未接入外部翻译插件、外部字体或在线文案服务。英文渲染结果在相同输入下逐字比较一致。新增中文字符后已更新字体子集与覆盖清单，并通过静态检查。
